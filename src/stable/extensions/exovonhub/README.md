# Exovon Hub

Welcome to Exovon Hub! This is a state-of-the-art agentic IDE extension powered by Google GenAI models (Gemini 3.5 Flash and Gemma 4 31B IT).

## Features

- Fully autonomous file modifications with speculative code edit cards.
- Interactive Workspace Agent integrated directly in your IDE.
- High-performance, edge-ready architecture.
- Secure environment token management.

## Installation

1. Download the `.vsix` package.
2. Open VS Code or VSCodium.
3. Go to Extensions -> Install from VSIX.
4. Select the `.vsix` file.

Enjoy the future of coding!
